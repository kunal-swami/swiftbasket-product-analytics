# Resume Positioning

## Project title

**SwiftBasket Quick-Commerce Product Analytics | Python, PostgreSQL, Pandas, SciPy, Matplotlib**

## One-line description

Built a reproducible synthetic event-level case study to diagnose new-user conversion decline, analyze retention and unit economics, and evaluate a randomized checkout experiment.

## ATS-friendly bullets

- Built an end-to-end quick-commerce Product Analytics case study using a reproducible **synthetic dataset of 80K users, 193K sessions and 913K events**, designing the event taxonomy and PostgreSQL model for funnels, payments, orders and experiments.
- Used advanced SQL and cohort/segment analysis to identify a **7.8% relative decline in seven-day first-order conversion**, decomposing the change into acquisition-mix (−0.33 pp) and within-segment checkout effects (−0.40 pp) and localizing friction to sub-₹399 carts.
- Evaluated a randomized fee-transparency experiment with **9.8K assigned users** using intent-to-treat, confidence intervals and guardrails; correctly concluded the observed **+0.22 pp lift was inconclusive (p=0.727)** and proposed prioritized follow-up tests.

Always retain “synthetic” or “portfolio case study” in the project description. Do not present the simulated outcomes as professional company impact.
